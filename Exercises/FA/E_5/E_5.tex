	\section{سوال اول}
	بسط  تیلور تابع \(\ln(1+z)\) را بیابید.
	\section{سوال دوم}
	تابع \(f(z)\) رو و داخل دایره واحد تحلیلی است، \(|f(z)| < 1\) برای \(|z| \le 1\) و \(f(0) = 0\). نشان دهید که \(|f(z)| < |z|\) برای \(|z| \le 1\).  
	\textit{راهنما: نشان دهید \(f(z)/z\) تحلیلی است و سپس با استفاده از فرمول انتگرال کوشی، \([f(z_0)/z_0]^n\) را بیان کنید و نهایتاً قدر مطلق‌ها و ریشه \(n\)-ام را در نظر بگیرید (این تمرین گاهی «قضیه شوارتز» نامیده می‌شود).}
	
	
	\section{سوال سوم}
	اگر \(f(z)\) تابع حقیقی متغیر مختلط \(z = x + iy\) باشد، یعنی \(f(x) = f^*(x)\)، و بسط لوران آن حول مبدأ، \(f(z) = \sum_{n=-N}^{\infty} a_n z^n\) باشد، نشان دهید که اگر \(a_n = 0\) برای \(n < -N\)، تمام ضرایب \(a_n\) حقیقی هستند.  
	\textit{راهنمایی: نشان دهید \(z^N f(z)\) تحلیلی است (با استفاده از قضیه موررا، بخش 11.4).}
	
	\section{سوال چهارم}
	
	اثبات کنید که بسط لوران یک تابع حول یک نقطه مشخص یکتا است؛ یعنی اگر
	\[
	f(z) = \sum_{n=-N}^{\infty} a_n (z-z_0)^n = \sum_{n=-N}^{\infty} b_n (z-z_0)^n,
	\]  
	آنگاه \(a_n = b_n\) برای همه \(n\) ها یکتا است.  
	\textit{راهنمایی: از فرمول انتگرال کوشی استفاده کنید.}
	\section{سوال پنجم}
	\begin{itemize}
	\item بسط لوران تابع \(\frac{e^z}{z^2}\) حول \(z=0\) را به دست آورید.
	\item بسط لوران تابع \(\frac{z e^z}{z-1}\) حول \(z=1\) را به دست آورید.
	\item بسط لوران تابع \((z-1)e^{1/z}\) حول \(z=0\) را به دست آورید.
	\end{itemize}
